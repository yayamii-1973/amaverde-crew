# AmaVerde Crew

Crew rotation, ship schedule and river conditions for river cruise ships — an installable web app.

**Open / install:** https://yayamii-1973.github.io/amaverde-crew/

- This repository holds **only the app (code)**. No crew data are here or on the server.
- Each ship loads its own Excel files; they stay in the browser of that device (Settings → Data → Backup to export / import).
- Installed from the browser (Chrome / Edge / Samsung Internet) it works offline and shows *“A new version of the app is ready”* when a newer version is published here.
